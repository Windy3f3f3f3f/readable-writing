# 完整示例：从散点笔记到可读报告

演示 `SKILL.md` 中的“新写文档”流程。素材是合成的实验笔记（仪表盘体，机检 4 分），
终稿为 0 分。

## 第零步:原始笔记(写作输入,不是交付物)

> - ✅ 主指标:错误率 12.4% → 6.1%
> - ✅ 对照组 11.8%(几乎没动)
> - ⚠️ 消融:去掉指令 → 回到 11.8% → **指令层是主活性成分**
> - ❌ 泛化:只测了 Qwen2.5,gemma 还没跑
> - 判分器好像有漂移(第 3 轮和第 1 轮同输入不同分,~2%)
> - 下一步:gemma + 判分器复核

## 第一步:列段首判断(每条 = 将来一段的第一句)

1. 这轮实验证明指令层是错误率下降的主活性成分。
2. 证据是消融:去掉指令,收益基本归零。
3. 结论目前只在 Qwen2.5 上成立,跨模型泛化待验证。
4. 判分器存在约 2% 的漂移,是当前最大的测量风险。
5. 下一步先复核判分器,再跑 gemma。

## 第二步:挂证据、标层次

- 判断 1 ← 事实:错误率 12.4% 到 6.1%,对照组 11.8%(run-0703 日志)。
- 判断 2 ← 事实:消融后回到 11.8%。
- 判断 3 ← 待验证:gemma 未跑。
- 判断 4 ← 事实:同输入两轮判分差约 2%;判断:漂移可能来自判分 prompt 的温度设置。

## 第三步:成文

> 这轮实验证明,指令层是错误率下降的主活性成分。错误率从 12.4% 降到 6.1%,而同批对照组仍在 11.8%,几乎没动(run-0703 日志)。
>
> 消融实验把这一点钉死了:去掉指令层,错误率回到 11.8%,收益基本归零。也就是说,起作用的不是数据量,是指令本身。
>
> 结论目前只在 Qwen2.5 一个模型上成立。gemma 还没跑,跨模型的说法先不下。
>
> 有一个测量风险要先处理:判分器出现了漂移,同样的输入在第 1 轮和第 3 轮差了约 2%。判断:漂移可能来自判分 prompt 的温度设置,尚未证实。
>
> 所以下一步的顺序是先复核判分器,再跑 gemma——测量工具不稳,后面的数字都白算。

## 对照笔记看差别

判断句领段,段段有数字和出处;「指令层是主活性成分」从加粗标签变成了有证据的完整论证;「待验证」显式说出来而不是塞在 ❌ 后面;段际用「消融把这一点钉死了」「有一个测量风险」这样的名词回指衔接,没有一个箭头、勾号和加粗。
