# 迁移完成记录

把旧服务器上的三个项目迁进了 monorepo。迁移前逐项核对了文件数：仓库外 5118 个文件、仓库内 544 个，与远端一致。

唯一的坑在认证配置。旧服务用的是环境变量注入，新框架读的是配置文件，起服务时报了两次 401。把密钥写进 secrets 文件、改回 600 权限之后，三个服务都起来了，健康检查连续跑了十分钟没有报错。

还剩两件事没做：一是旧域名的重定向要等 DNS 生效，大概明天中午能验证；二是备份脚本还指向旧路径，我改好了但没敢在工作时间重启定时任务，准备今晚低峰期切。

这次学到的教训：迁移清单里应该把「谁在读这个路径」也列进去。备份脚本这种低频消费者最容易漏，这次是翻 crontab 才想起来的。
